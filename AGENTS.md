# smsflow-api-examples Agent Instructions

This repository is intended to be public customer-facing sample code for the SMSFlow HTTPS API.

- Do not commit real SMSFlow credentials, phone numbers, tokens, customer data, logs, or screenshots containing secrets.
- Use `.env.example` for placeholder configuration.
- Keep examples small, readable, and aligned with `https://docs.smsflow.co.za/`.
- Prefer examples that developers can run locally with environment variables.
- If an example sends an SMS, make it obvious that it will consume test credits.
